ACT-R + Fatigue Module Utility Explorer

Compare multiple “scenarios” (e.g., phases) by adding additional parameter sets and biomath predictions.
Each scenario plots Utility Threshold (UT) and Current Utility (U) over time on task, as well as the Probability of Microlapse.
Equations used:
UT(t) = ut × (1 − utbmc × biomath) × (1 + minutes)^utmc
U(t) = iu × [(1 − fpbmc × biomath) × (1 + minutes)^fpmc] + egs
P(microlapse at t) = P(U < UT) = P(egs < UT − μ)
Time (t) is sampled at a fixed 1-second step.

Scenario controls
Add scenarios to overlay additional UT/U curves with different parameters and biomath prediction. All scenarios share the same noise seed so differences are easier to compare.
Use the checkbox to “unlock” a parameter for manipulation. If unchecked, the scenario uses the suggested default value.
How scenario “locking” works
Each scenario stores a biomath scalar, parameter values, a per-parameter lock state, and a fixed color. Locked parameters revert to suggested defaults (so you can isolate effects cleanly).
